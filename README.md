# blizz

Animated terminal setup wizard for Kernelle Software CLI tools.

## Features

- Bobbing mascot animation with squash/stretch and eased timing
- Full-screen alternate buffer layout with dynamic centering
- Character-by-character decode text effect
- Centered prompt primitives (text input, confirm)
- Event-driven render loop with terminal resize support
- Builder API for defining multi-step wizard flows
